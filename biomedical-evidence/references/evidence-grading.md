# 医学证据分级

## 先按问题选择设计

| 问题 | 优先证据 |
| --- | --- |
| 治疗/预防收益 | 当前指南、系统综述、高质量 RCT |
| 罕见或长期伤害 | 大型队列、病例对照、药物警戒，RCT 可能功效不足 |
| 诊断准确性 | 与合适参考标准盲法比较的前瞻性研究 |
| 预后 | 代表性起点队列和经过验证的预测模型 |
| 患者体验/可接受性 | 适当抽样的定性或混合方法研究 |

## 确定性维度

从研究设计起点出发，根据以下因素降级或升级，并说明理由：

- 偏倚风险：随机、隐藏分配、盲法、失访、终点切换、选择性报告。
- 不一致：方向、效应量和人群间差异是否可以解释。
- 间接性：研究人群、剂量、对照、结局和地区是否匹配当前问题。
- 不精确：样本、事件数和区间是否跨越有临床意义的收益/伤害。
- 发表偏倚与利益冲突。
- 大效应、剂量反应或残余混杂只会削弱观察到效应时，可谨慎升级观察证据。

最终使用“高/中/低/极低/不可判断”，并附一句原因，不只给标签。

## 数字表达

- 同时报基线风险和时间窗：例如每 1000 人一年减少多少事件。
- 相对风险不能单独成为生活建议；能计算时给绝对风险差及 NNT/NNH。
- 连续结局解释量表范围和最小临床重要差异。
- 不把统计显著等同于临床重要，也不把“无显著差异”写成“证明相同”。

## 注册与版本核对

- 用 NCT/其他注册号核对预设主要/次要结局、计划样本和时间点。
- 对照论文日期与注册/修改历史，标记事后注册或主要终点变化。
- 预印本、会议摘要、正式论文和更正后的版本分开标记。
- 撤稿或 expression of concern 的研究不得作为正面承重证据；说明它是否影响综述结论。
