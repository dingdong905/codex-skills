# 学术论文检索与生活证据

找到真正相关、可以核验且值得读的研究，并清楚区分“论文说了什么”“证据有多强”和“对现实生活能说明什么”。优化研究价值和新增信息量，不追求链接数量。

## 先确定任务形态

从用户请求推断以下要素；请求清晰时直接执行，不必机械追问：

- 目标：前沿追踪、入门阅读单、回答具体问题、争议核查、系统综述、引用/作者追踪或开放全文。
- 范围：学科、年代、语言、地区/人群，以及需要经典研究、最新研究还是两者兼顾。
- 结果深度：轻量候选表、精选深读，或可复现的系统检索。

正式系统综述或 PRISMA 请求需读取 [references/systematic-review.md](references/systematic-review.md)。

## 检索工作流

1. 把主题改写成 2–4 个互补查询：核心概念、同义词/缩写、机制或结果变量、反证词；默认同时构造英文查询，中文或其他语言主题再补本地语言查询。
2. 读取 [references/source-routing.md](references/source-routing.md)，按学科选择至少两个互补索引。优先使用当前环境已有的专业连接器、官方 API、浏览器或本地资料；不得假设某个工具一定存在。
3. 第一遍只取标题、作者、年份、摘要、来源、标识符、文献类型、引用数和开放获取状态。通常扫描 20–40 条，再筛到 5–10 条深读。
4. 以 DOI、PMID/PMCID、arXiv ID 去重；缺少标识符时用规范化标题、年份和第一作者交叉匹配。合并记录时保留各平台差异。
5. 同时保留三类材料：奠基性研究、最新进展、最强可信反证。对关键论文执行向前/向后引文追踪。
6. 深读决定结论的少数论文，抽取研究问题、设计、样本/语料、方法、主要结果、效应量、不确定性、局限、资金/利益冲突和数据/代码可得性。
7. 对承重论文核验题名、作者、年份、期刊/会议和 DOI；再检查勘误、撤稿、expression of concern、同行评审状态和最新版本。预印本不得默认为已通过同行评审。
8. 当新增论文主要重复已知结论、关键争议已有正反证据、剩余缺口不会改变答案时停止。不要用无限搜索掩盖不可获得的数据。

## 选择“值得读”的论文

按以下顺序判断，不得只按引用数或期刊名排序：

1. 与问题、人群、情境和结果变量的匹配程度。
2. 研究设计是否能支持作者和用户想要的推断。
3. 方法质量：样本、对照、测量、统计功效、混杂、选择偏差和多重比较。
4. 结果的效应量、区间和可重复性，而不仅是显著性。
5. 是否有独立复现、系统综述、开放数据/代码或透明的材料。
6. 时效性和引用影响；引用数应按论文年龄和学科惯例理解。

### 前沿计算机与大模型

- 同时找近 3–6 个月前沿论文、近 2–3 年关键路线和奠基论文；新论文低引用不是降级理由。
- 提取模型/数据/算力规模、评测集、基线、消融、方差、推理成本和代码/权重状态。
- 检查数据污染、基准饱和、不可比计算预算、只报最好一次结果，以及技术报告与正式同行评审版本的差异。
- “刷新榜单”不等于真实能力或生活价值；优先看跨任务复现、成本、稳健性和失败边界。

### 人文、历史与哲学

- 论文不是唯一高价值载体；专著、书章、权威版本、档案、原始文本和考古/历史数据可能更重要。
- 区分一手材料、后世解释与理论论证。评价来源批判、语境、版本、翻译和学术争议，不能用引用数替代论证质量。

### 医学、健康与心理学

- 临床或生活干预优先找最新指南、系统综述/Meta 分析和高质量随机试验；观察性研究通常只能支持关联。
- 检查试验注册、主要终点切换、绝对风险、NNT/NNH、失访、异质性、发表偏倚和利益冲突。
- 不把动物、体外、小样本、单中心或预印本结果直接外推为个人医疗建议。

## 从证据到生活启示

用户询问“对我有什么用、该怎么做”时，必须读取 [references/evidence-to-life.md](references/evidence-to-life.md)。核心要求：

- 先说明证据适用于谁、在什么条件下成立，再讨论能否迁移到用户情境。
- 报告绝对效果或现实量级，不用相对百分比制造夸大印象。
- 把结论分为：可以低成本尝试、值得继续观察、需要专业人士参与、证据不足不应行动。
- 说明成本、风险、机会成本、可逆性和观察指标；健康、财务或其他高风险决定不因单篇论文而改变。
- 历史、哲学和社会研究可以改善视角与判断，但不要伪装成实验性因果证据。

## 输出规范

先给结论与证据强度，再按需要提供：

- 精选论文表：题名、年份、文献/研究类型、为什么值得读、DOI/PMID/arXiv、开放全文链接。
- 综合判断：一致发现、分歧、最强反证、适用边界和仍未知内容。
- 对生活的意义：现实量级、适用条件、低风险行动或不行动理由。
- 检索说明：数据库、查询式、截至日期、筛选标准和访问缺口。

所有重要主张紧邻引用。引用至少包含作者、年份、题名和稳定标识符/官方链接；找不到原始记录时明确标注“未核实”，绝不补造论文、DOI、页码或引用数。引用数必须注明平台和查询日期。

## 全文与合规边界

- 只获取出版商、作者、机构仓储、arXiv/PMC 等合法开放版本；不绕过付费墙、验证码、机构权限或访问控制。
- 页面可访问不等于 PDF 可下载。无法获得全文时说明只有摘要证据，并给出图书馆、馆际互借或联系作者等合法路径。
- 批量下载前先列清单和保存目录，除非用户已明确要求下载全部开放论文。
- 医学检索用于信息理解，不代替诊断、处方或急救判断；存在现实健康风险时建议咨询合格专业人士。

## Token 纪律

- 先读元数据和摘要，筛选后才读全文；不把几十篇全文一次性装入上下文。
- 每篇深读后压缩成“主张—证据—局限—标识符”，后续只携带这份证据账本。
- 只有需要系统综述、学科路由或生活转化时才加载相应 reference。
- 用户只提供现成论文并要求总结时，使用 `research-summarizer`；需要发现、更新或交叉核验论文时使用本技能。
