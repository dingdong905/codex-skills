# 把研究证据转化为生活判断

只在用户关心现实含义、个人选择或行动建议时读取。目的不是把论文包装成指令，而是判断证据是否足以支持某种行动。

## 五层转化检查

### 1. 主张强度

- 论文报告的是描述、相关、预测、机制线索还是因果效应？
- 标题或摘要是否把相关性写成因果？实际设计最多能支持哪一级主张？
- 统计显著不代表效果重要；优先记录效应量、置信/可信区间和基线水平。

### 2. 证据成熟度

- 单篇研究、预印本或探索性分析：只能形成假设或关注信号。
- 多个独立、方法相近且结果一致的研究：可提高信心，但仍检查共同偏差。
- 系统综述/Meta 分析：检查检索日期、纳入质量、异质性、发表偏倚和“小垃圾进、大垃圾出”。
- 指南或共识：检查制定机构、证据分级、利益冲突和更新时间。

### 3. 可迁移性

比较研究与现实情境：

- 人群：年龄、性别、疾病、文化、职业、社会经济状况。
- 干预/暴露：剂量、持续时间、执行质量、对照条件。
- 情境：国家制度、时代、气候、技术条件、医疗资源。
- 结局：实验室代理指标还是真实生活结果；随访是否足够长。

任何关键维度明显不匹配时，下调结论强度并说明原因。

### 4. 实际收益与代价

- 尽量把相对变化还原为绝对变化。例如“风险降低 20%”需同时给出基线风险；从 10% 到 8% 是下降 2 个百分点。
- 医学研究在数据允许时给出 NNT/NNH，并区分短期副作用和长期风险。
- 考虑金钱、时间、注意力、机会成本、隐私、公平性和可能的反作用。
- 区分平均效果与个体差异；不要承诺个人一定获得总体平均收益。

### 5. 行动门槛

| 类别 | 适用情形 | 输出方式 |
| --- | --- | --- |
| 低成本可逆试验 | 风险低、成本小、可观察结果 | 给出小规模试行、周期、观察指标和停止条件 |
| 值得持续观察 | 方向有希望但证据早期或不一致 | 说明等待哪类复现、指南或长期结果 |
| 专业人士参与 | 医疗、心理危机、法律、重大财务或高风险改变 | 提供与专业人士讨论的证据要点，不代替其判断 |
| 不应据此行动 | 单篇弱证据、明显不适用、风险大于潜在收益 | 明确说明为什么证据不足 |

## 不同学科怎样“有用”

- 计算机/LLM：关注可靠性、成本、隐私、失败模式和真实工作流增益；排行榜提升不自动等于值得采用。
- 医学/心理：关注绝对健康结局、伤害、适用人群和专业指南；不得建议自行停药、改药或替代紧急医疗。
- 社会学/地理：用于理解结构、环境和群体差异；群体平均不能给个体贴标签。
- 历史：提供制度与行为的长期比较，但类比必须说明时代差异，不能把历史重复当作定律。
- 哲学：帮助澄清概念、价值冲突和论证前提；其价值不依赖实验效应量，也不应伪装成经验因果结论。
- 天文/基础科学：生活价值可以是世界观、科学素养和认知校准，不必强行制造即时实用建议。

## 建议输出模板

1. **研究目前支持什么**：一句话结论和证据强度。
2. **现实量级**：绝对效果、时间尺度和最重要的不确定性。
3. **是否适用于当前情境**：匹配点与不匹配点。
4. **可采取的最小行动**：若适合，给低风险、可逆、可观察的步骤。
5. **不要据此做什么**：指出越界外推或高风险行动。
6. **更新信号**：未来什么新证据会改变判断。
