# 未覆盖学科的通用回退

这是临时策略，不代表该领域已经达到专业 Skill 的深度。

1. 明确问题、时间、地区、语言、材料类型和用户希望做出的判断。
2. 至少选择两个互补来源：一个广覆盖学术索引，加一个领域数据库、出版社、学会或档案目录。
3. 同时检索经典材料、最新研究和最强反证；人文学科允许专著、书章、权威版本、档案与一手资料成为核心证据。
4. 以 DOI、ISBN、稳定馆藏号或规范化题名去重并核验出处。
5. 分开评价来源真实性、方法/论证质量、代表性、语境和解释争议，不用引用数替代质量。
6. 输出“已知—争议—未知—现实启示”，并记录查询式、数据库、截至日期与访问限制。

停止条件：互补查询不再带来会改变结论的新材料，且关键正反观点都有代表性来源。最多尝试 3–5 个高质量查询后仍无结果，应报告缺口而不是虚构来源。
