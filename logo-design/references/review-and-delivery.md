# 评审与交付

在实际用途下检查：应用图标或小尺寸处的轮廓、实际字标读法、单色/反白、浅深背景、留白与锁定比例。复杂阴影和细线是否适合印刷/刺绣按用户目标判断，不强制所有风格都用同一尺寸或线宽。

图片查看是必要的视觉证据；文件头或 SVG XML 通过不能证明标识可读或准确。解释候选差异，迭代只改用户指出的重点，保留已确认内容。

交付品牌名称准确的预览和文件链接，说明位图像素或矢量类型、透明状态、变体、可编辑源和用途约束。最终项目资产存入用户指定目录，避免只引用工具默认生成路径。不得把概念图表述为已完成商标/侵权审查或已确认可注册；用户需要此类审查时另行建立证据范围。

素材变体和最小尺寸规则只有实际试过后才标注“已验证”。没有做某项测试就保留为待验证项。
