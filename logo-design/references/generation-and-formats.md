# 生成路径与格式

位图创作/修改读取环境 imagegen 技能并使用内置工具，参数以当前 schema 为准。参考图先查看再编辑，明确保留身份、文字和比例；新图只补充与 brief 有关的构图、风格和约束。若工具不可用说明缺口，只有用户选择 CLI/API 后才走对应回退路径，不调用上游 Gemini 脚本。

需要准确字标时优先原生文字排版；用户要求整张生图字标时逐字验收，不能默认生成文字一定正确。透明图需请求真实 alpha 并查看不同背景，不能靠白色棋盘图假装透明。

| 格式 | 能承诺的交付 | 边界 |
| --- | --- | --- |
| PNG | 位图概念、透明素材或指定尺寸输出 | 固定像素，放大会暴露细节问题 |
| SVG | 真实路径/形状及必要的可编辑文本 | 不得仅嵌入 PNG 冒充矢量；字体和外链资产需说明 |
| PDF | 按用途输出的展示或生产文件 | 展示 PDF 不自动满足印刷、矢量或色彩要求 |
| AI/EPS | 仅在环境实际支持导出时交付 | 不能改扩展名或声称工具不存在的导出能力 |

已有 SVG 在其源中修改，用户要求矢量时使用真实几何与字形方案；自动描摹产生的路径需清理与验收。保留用户要求的可编辑性，文字转曲前保留可编辑源并确认字体授权要求。
