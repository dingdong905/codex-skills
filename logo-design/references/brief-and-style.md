# 简报与风格判断

以准确品牌名称、受众、使用场景、现有标识、品牌色/字体和输出格式形成简报。用户只要一个标识时不扩展成完整 CI 包。已有视觉身份应明确哪些可以变化。

| 标识类型 | 适用判断 | 评审重点 |
| --- | --- | --- |
| 字标 | 名称本身承担识别，用户需要准确文字 | 字距、笔画、字体许可、中文/拉丁组合 |
| 字母标 | 名称长或缩写已被用户认可 | 缩写是否准确、小尺寸混淆 |
| 图形标 | 需要独立视觉符号 | 轮廓、语义、与相似标识的可区分性 |
| 组合标 | 图形与名称共同使用 | 水平/竖版关系、最小尺寸、拆分规则 |
| 徽章/吉祥物 | 内容和场景有明确需要 | 细节数量、缩小后可读性及单色版本 |

风格资料可检索极简、几何、复古、负空间、线性、手绘等词。选择理由应联系实际内容与使用环境，不用“某行业必须蓝色”或“某颜色保证信任”作事实。

列出用户确认的要求与候选建议；未知输入保持待确认，不填虚构品牌故事。候选差异优先体现在轮廓、构造和文字关系，而不是只换色。
