# 教学循环与掌握检验

只读取与当前主题类型相关的小节。混合主题按层拆开，不要把全部循环一次施加给用户。

## 知识型：解释机制

适用于“为什么、如何运作、怎样排错”。

1. 给一个核心心智模型和不超过三个新名词。
2. 在展示答案前让用户预测现象或解释原因。
3. 用真实实验、权威例子或明确标注的推演进行验证。
4. 对照预测与结果，定位具体误解。
5. 要求用户用自己的话复述，并回答一个迁移题。

通过标准：因果链无关键缺口，且能把模型用于一个新场景。复述原句不算通过。

## 技能型：形成可重复动作

适用于编程操作、写作、演奏、运动分解或工具使用。

1. 展示合格示范和可观察标准。
2. 将动作拆到一次只纠正一个主要变量。
3. 让用户独立尝试，记录作品或真实输出。
4. 对照标准指出最大差距，给一个可执行修正。
5. 先分块练到基本稳定，再交错混合不同分块。

通过标准：在减少提示后仍能独立做出来。能讲清步骤但做不出来不算通过。

## 判断型：校准分辨力

适用于设计品味、文本鉴赏、棋局判断和无唯一答案的评价。

1. 使用真实、可追溯的高质量样本，不用 AI 生成品冒充范本。
2. 成对比较，让用户先给“判断 + 理由”。
3. 引入最强反方解释，要求用户回应。
4. 用陌生样本做盲测，观察理由是否稳定。

通过标准：能指出决定判断的特征，并在新样本中保持一致；不是迎合导师结论。

## 失败后的降级

- 第一次失败：指出误解或动作差距，立即反馈。
- 同一点连续两次失败：缩小任务，先给 worked example，再让用户补完相邻步骤。
- 多次失败且前置知识不足：暂停当前单元，补最小前置内容。
- 环境不可用：改为推演或模拟，并显式标记“未实验验证”。

## 间隔与交错

- 通过后生成少量提取题，而不是摘要卡。
- 答对流畅则扩大间隔；答对但卡壳则保持；答错则缩短并补反馈。
- 新动作先分块练，稳定后再交错；提前告知用户交错练习的即时表现可能下降。
- 复习优先抽取容易遗忘、曾经答错或高迁移价值的内容。

## 每轮最小记录

只在用户要求记录时保存：日期、本轮目标、真实表现、主要差距、是否通过、下一步。不要保存推测出的性格、能力标签或敏感信息。
