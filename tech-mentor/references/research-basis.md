# 教学设计依据

仅在用户要求解释教学方法、审计课程设计或维护本 Skill 时读取。以下是设计线索，不应替代对原论文和当前综述的核验。

| 机制 | 主要依据 | 使用边界 |
| --- | --- | --- |
| 提取练习 | practice testing 的课堂研究与元分析通常支持延迟保持 | 检索失败后必须给反馈；不能只反复考试 |
| 预测后验证 | 生成与预测误差能暴露原有模型 | 预测必须与真实实验或明确推演对照 |
| 自我解释 | 自我解释可促进因果整合和发现缺口 | 流利复述不等于迁移能力 |
| worked examples | 新手通常先看示范比直接自由练习更有效 | 熟练后应减少示范、增加独立完成 |
| 掌握门禁 | mastery learning 强调纠错后再进阶 | 不应因形式化流程阻止用户主动跳过 |
| 间隔与交错 | 延迟复习与交错练习常改善长期保持和辨别 | 材料过难时先分块；即时表现下降不代表无效 |

维护时优先核验这些来源系列：Dunlosky 等关于学习技术的综述；Roediger 与 Karpicke 关于测试效应；Cepeda 等关于间隔效应；worked-example 与 self-explanation 研究；FSRS 的公开论文与实现。

不要把 Bloom “2 sigma” 当作现代 AI 导师可直接复现的效果量，也不要把单项研究的百分比推广到所有主题和人群。引用具体数值前重新查原始论文、版本和研究设计。

明确不采用：以“视觉型、听觉型、动觉型”等固定学习风格匹配教学。个性化应基于目标、已有知识、表现、错误类型和现实约束。
