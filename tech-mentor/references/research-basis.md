# 教学设计依据与适用边界

仅在用户要求解释方法、审计课程或维护本 Skill 时读取。以下是设计线索，不是已证明本 Skill 有效的结论。引用论文和具体效果量前重新核验原文、研究对象、设计与时效。

| 方法 | 可支持的设计方向 | 不能据此推出 |
| --- | --- | --- |
| 提取练习与反馈 | 在适当难度下尝试提取，失败后给反馈 | 每轮都应测验，或直接讲解不算教学 |
| 生成与预测 | 有背景时预测可暴露现有解释与误解 | 必须先猜、只有预测错误才能学习 |
| 自我解释 | 解释关系可帮助整合与发现缺口 | 不会流利复述就没学会 |
| 示例学习 | 新手可先看示范，再逐渐减少支持 | 必须先让新手失败再给示范 |
| 掌握学习 | 明确标准、具体纠错与再次尝试 | 普通对话必须设置固定门禁 |
| 间隔与交错 | 按目标、基础与实际表现安排巩固 | 固定倍率就是 FSRS，挫败越多效果越好 |

## 来源线索

原版本记录了以下研究或研究系列；这里保留出处供按需核验，不沿用未重新核验的精确数值或跨领域推广：

- Dunlosky 等（2013）：学习技术综述；Yang 等（2021）、Adesope 等（2017）：测试或提取练习元分析。
- Roediger 与 Karpicke（2006）：测试效应；生成、预测误差与测试效应并非同一个机制，不能用单篇测试效应论文证明强制预测规则。
- Chi 等：自我解释；Van Gog 与 Sweller（2015）：示例学习；Fiechter 与 Benjamin（2018）：检索失败与反馈的边界。
- Cepeda 等（2008）：间隔效应；Rohrer 与 Taylor（2007）、Sana 与 Yan（2022）：交错练习。
- Ericsson 系列：刻意练习；Karpicke 与 Blunt（2011）：提取练习与概念学习。
- Bloom（1984）、VanLehn（2011）、Kulik 与 Fletcher（2016）：掌握学习与辅导系统。不能把“2 sigma”直接当作现代 AI 导师的预期收益。
- FSRS 的公开论文与实现；原版本列出的 DOI 10.1145/3534678.3539081 与 10.1109/TKDE.2023.3251721 需核对其与具体算法主张的对应关系。当前 Skill 没有实现 FSRS。
- Pashler 等（2008）：学习风格匹配的证据审查；不按视觉型、听觉型等固定标签匹配课程。

## 本次设计选择的性质

默认对话带学、按负担调整信息量、允许直接解释及从生活问题切入，是针对教学体验的设计选择，仍需实际使用验证。没有声称它们作为一个组合已经获得普遍优于其他模式的实证结果。

评估同时看用户是否愿意继续、误解能否澄清、减少支持后能否应用与适当延迟后的保持。不能只看聊天长度、用户说懂了或答题数量。医学理论、艺术判断与技能训练的材料和证据标准分别核对。

本轮维护没有重新检索或核验上述论文；出处是核验线索，不是新增研究结果。原版本中的学习过程与个人授权记录不作为当前执行依据。
