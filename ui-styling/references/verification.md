# 实现验证

选择与改动相称的验证，不为了小样式变化新建镜像实现的测试。

1. 构建/类型检查确认类名、导入和实际 prop 有效；动态拼接类名在源代码里出现并不等于构建器会生成。
2. 打开受影响页面，检查窄屏、桌面、长文本与缩放；截图有助比较但不能证明行为。
3. 键盘检查 Tab 顺序、可见焦点、焦点不被 sticky/overlay 遮挡、弹层 Escape 与焦点返回。
4. 表单标签、description/error 的关联与错误保留；颜色不是唯一状态指示。
5. 项目支持的明暗主题分别检查文本与控件对比；普通文字 4.5:1、大文字及必要非文本状态 3:1 按角色使用。
6. 动效有 reduced-motion 路径，装饰不挡点击、焦点或阅读。触摸控件按目标平台判断，Web CSS px 不混用原生 pt/dp。

交付时列出实际执行的检查和关键未验证项，不将“使用了 Radix/shadcn”表述成自动通过 WCAG。文档资料与项目版本冲突时以实际代码和对应版本官方文档为准。
