# 数据源注册表

| 数据源 | 主要用途 | 强项 | 关键限制 |
| --- | --- | --- | --- |
| OpenAlex | 广域发现、引用和 OA 状态 | 跨学科、结构化、可标撤稿 | 摘要可能缺失；标记并非完整勘误审计 |
| Crossref | DOI 与出版元数据核验 | DOI 权威注册元数据 | 不评价质量；摘要和 OA 信息常不完整 |
| PubMed | 生物医学发现与 PMID 核验 | MeSH、文献类型、撤稿相关记录 | 收录不等于质量；全文通常不在接口中 |
| arXiv | AI/计算机最新预印本 | 版本时间清楚、更新快 | 不是同行评审；元数据不等于复现成功 |
| ClinicalTrials.gov | 试验注册与状态核验 | NCT、预设终点、招募状态 | 注册结果可能缺失或滞后；不等于论文结论 |

所有接口均可能限流、短暂失败或返回缺字段。脚本设置明确 User-Agent、超时和错误输出；在线结果必须记录抓取日期。

arXiv API 连续返回 429 时，脚本会透明回退到 OpenAlex 的 arXiv 来源过滤，并在 warnings 和 provenance 中标明。回退结果在正式引用前仍需再次核验 arXiv 记录与版本。
