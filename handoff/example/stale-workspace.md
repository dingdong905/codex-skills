# 合成场景：交接后文件发生变化

这是教学场景，不是本机项目记录。输入目录、代码和测试结果均为合成数据。

用户让接手者继续修复一个 Python 工具。交接称：目标是保留 Unicode 输出；先前在文件哈希 H1 下测试通过。snapshot 保存了关键文件的 H1。交接之后，另一编辑者将文件改成 H2，但没有再运行测试。

预期：check 检出文件哈希变化；接手者检查当前 diff 和 Unicode 行为，保留用户修改，重新验证受影响行为。不能沿用旧“通过”结论，不能 reset 文件去追求快照一致。

用户只要求准备交接时：生成文件与首句，不创建新聊天。用户明确要求新建聊天续做时：发送完整短交接；目标在另一个新 worktree 时，核验源未提交代码是否真的已传递，未传递则说明差异。

边界：字节匹配只证明产物一致；它不证明测试覆盖充分或所有外部作业已经完成。此合成场景不提供发布、消息发送、部署或删除授权。
