# 图表与页面布局

将上游 slide layouts/charts 的比较、趋势、构成、漏斗与紧凑指标模式转为 PPTX 页面判断，不导入 Chart.js/CSS 图表实现。

| 数据问题 | 适合表达 | 需避免 |
| --- | --- | --- |
| 同口径类别比较 | 条形图；长标签可用横条 | 排名和绝对差异被截轴或透视扭曲 |
| 时间变化 | 折线；统一间隔与单位 | 把不规则时间间隔画成等距且不说明 |
| 构成 | 份额表、堆叠条；少量份额可用圆饼 | 类别过多、总和不成立、用构成暗示规模 |
| 转化步骤 | 阶段数量/比率与标明分母的漏斗 | 不是顺序过程却套漏斗，跨期 cohort 不可比 |
| 目标差异 | 实际/目标比较与差异分解 | 用只有仪表盘装饰的 gauge 隐藏数值 |
| 精确读取 | 简短表格 | 把整张原始表缩成小字 |

页面标题说发现，图表展示关系，少量注释解释证据与动作；指标卡只放当前决策需要的量。Sparkline 是摘要，重要结论要有单位、范围、源与可读详细图。

图表按用户要求在 PPTX 中保持可编辑，必要数据表/文字替代随材料保留。系列除颜色外用标签、线型或形状区分，不以“加了图例”证明可访问性。渲染后检查轴、图例、标注与 CJK 文本，交付前仍走 deck-review。
