# 微观领先数据源矩阵

仅选择与研究对象因果链相关的条目。每项数据计划都要写清“字段—来源—频率—验证方式”，不要为了覆盖面机械拉取全部类别。

| 类别 | 优先字段 | 首选原始来源 | 需要辨别的问题 |
|---|---|---|---|
| 订单与采购 | 买方、产品、型号、数量、单价、金额、交付、验收、付款、是否框架订单 | 政府与企业采购平台、公共资源交易、客户采购公告、合同原文 | 意向还是确定订单；是否重复计算；是否可取消 |
| 产品价格 | 现货/合约/渠道/中标价、折扣、地区价差、配置、税运口径 | 产业报价、经销商、采购结果、产品页面、历史快照 | 有价无量；配置变化；促销和返利 |
| 物流与实物流 | 品类数量、重量、金额、单价、港口、航线、目的地、船期、提单 | 海关、港口、航运、铁路、公示物流记录 | 抢运、转口、行业货量与公司货量混淆 |
| 库存与交期 | 原料/在制/成品/渠道/客户库存、缺货率、交期、退货 | 公司与上下游披露、渠道调查、报价平台、项目现场记录 | 主动备货还是滞销；库存位置转移 |
| 产能与建设 | 环评、能评、土地、施工、设备、设计产能、投产、用电、开工 | 生态环境、发改、工信、自然资源、招投标、地方政府 | 规划、在建、试产与有效产能混淆 |
| 客户行为 | 资本开支、预算执行、使用、活跃、复购、扩容、退货、售后 | 客户公告、采购记录、产品使用数据、开发者与运营数据 | 试验采购还是生产使用；渠道压货 |
| 技术兑现 | 送样、认证、兼容、小批量、量产、性能、功耗、故障、版本更新 | 认证机构、客户、产品文档、代码/开发者生态、专利 | 公司自述与客户验证的差异 |
| 组织与人才 | 岗位、地区、职能、薪酬、班次、核心人员变动 | 公司招聘页、招聘平台、工商与公告 | 补缺、外包与真实扩张混淆 |
| 供应链 | 供应商、采购量价、账期、预付、替代来源、进口依赖 | 供应商公告、海关、采购、认证与公司披露 | 供应约束、议价权和关联交易 |
| 政策执行 | 生效日、适用范围、采购条款、审批、拨款、补贴到账、执法 | 政府、监管、法院和交易所原文 | 正式执行、征求意见与传闻混淆 |
| 资本与治理 | 融资、质押、担保、关联交易、激励、稀释、并购、承诺兑现 | 交易所、工商、司法、债券与公司公告 | 高估值是否转化为高回报再投资 |
| 财报验证 | 分部收入、利润、现金流、应收、存货、预付、合同负债、资本开支 | 审计财报、附注、业绩会 | 合并口径、一次性项目、确认时点 |

## 频率与时效

- 事件驱动：订单、中标、认证、项目审批、交付和治理事项。
- 每周：渠道价格、交期、招聘、招标进度和产品活动。
- 每月：海关、港口、产量、项目建设、用电和行业库存。
- 每季度：财报、客户资本开支和资产负债表验证。

同时保存 `observed_at`、`published_at`、`collected_at`。后续分析只使用在当时已经公开的信息，避免前视偏差。

## 领先关系

为每项数据写明它领先哪个财务或经营结果，以及中间可能断裂的环节。例如只记录一般形式：

`采购/订单 → 生产或交付 → 验收或使用 → 回款 → 财报确认`

链条不能被证据连接时，保留为观察，不得升级为结论。
