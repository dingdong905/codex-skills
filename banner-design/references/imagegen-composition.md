# 生图素材与可编辑合成

默认使用环境内置 imagegen 路径，参数能力以工具当前 schema 为准。不要传入它不存在的 size、output-dir、Gemini model 或 API Key 参数。

## 适合生图的部分

照片、插画、背景、纹理与位图变体；Logo、准确文案、价格和规则说明优先使用已确认素材及可编辑排版。用户明确想要整张生图海报时可按其要求生成，并指出仍需核对实际尺寸与文字。

提示按任务使用这些字段，不必填满模板：

- 用途与题材：品牌/活动提供了什么、谁会看到。
- 风格与色彩：用户指定的风格、品牌色与参考图角色。
- 构图：目标宽高关系、主体位置、文字需要的留白；不要求与实际版式无关的固定 CTA 方位。
- 文本：需要工具生成文字时逐字引用；作为排版背景时明确无文字。
- 约束：保留用户资产的比例和身份、需要透明时请求真实 alpha。

工具输出后查看素材。项目引用的图片应复制到项目可管理的资产路径；不要假设工具有目的路径参数，也不要把用户项目引用永久指向工具默认生成目录。

## 合成与迭代

使用固定画布 HTML/CSS 或项目既有设计源编排图片、文本和 Logo。明确图片裁切使用 cover 还是 contain；不拉伸主体和 Logo。多尺寸版本重新处理换行、安全区和主体位置；不要仅缩放同一个排版。

现有位图修改走 imagegen 的编辑流程；不要编写 Python/图片脚本代替用户要求的位图编辑。CSS 原生排版和截图导出不属于修改现有位图的回退路径。需要矢量源时按用户指定格式创建真实可编辑源，不能声称生成的 PNG 是矢量。
