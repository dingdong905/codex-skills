# 尺寸与风格参考

以下是上游快照中的常见制作尺寸，不是实时平台规格。用户提供的活动/广告后台规格优先，发布前核对当前平台要求。

| 用途 | 常见尺寸 px | 注意事项 |
| --- | --- | --- |
| X/Twitter 封面 | 1500×500 | 宽画布；头像遮挡与设备裁切 |
| LinkedIn 个人封面 | 1584×396 | 头像位置与四比一裁切 |
| YouTube 频道图 | 2560×1440 | 常见中央安全区 1546×423，仍需核对平台预览 |
| Instagram 方图 | 1080×1080 | 正方形只适用于选定版式，不代表所有 feed 比例 |
| 竖版 story | 1080×1920 | 上下平台操作区可能遮挡内容 |
| Facebook 封面 | 820×312 | 显示规格随设备变化，按当前页面预览确认 |
| 展示广告矩形 | 300×250 | 字号与信息量需适应小画布 |
| 展示广告长横条 | 728×90 | 素材重新排版，不能直接等比缩小海报 |
| 网页 hero 素材 | 根据页面容器定制 | 设计像素不等于实际响应式显示范围 |

安全区按实际平台遮挡和裁切确定，中央 70–80% 可作为初步构图参考，不能代替平台模板。静态图片中画出的 CTA 不是可点击控件，44px 交互命中区规则不直接适用于图片；网页真实按钮另按界面规范实现。

## 风格选择

按品牌和内容选一到两种主要表达：留白与极简、强字体、摄影、插画、几何、编辑版式、复古、双色、拼贴、3D 或柔和渐变。风格之间的差异应体现在构图和信息层级，不只换色。现有品牌不适合时不要机械套用某个风格。

少量字体角色、清晰主信息和有意图的行动提示通常更易读；按实际文案长度和目标显示尺度调节。不要使用过时的“Meta 强制 20% 文字占比”规则；广告政策以当前平台规定为准。

## 印刷

取得印厂的实物尺寸、出血、色彩空间、ICC profile 与有效分辨率要求。换算参考：px = mm / 25.4 × ppi。DPI 元数据不提升真实像素质量，网页 RGB PNG 也不是 CMYK 生产文件。需要印刷文件时使用合适的可编辑/PDF 流程并记录尚未确认的要求。
