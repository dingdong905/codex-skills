# 导出与验证

## 浏览器或设计源导出

打开目标 HTML/设计源，确认画布容器的逻辑宽高和导出倍率。使用项目已有的浏览器截图工具或环境实际支持的浏览器能力；读取当前工具文档，不调用不存在的 Chrome MCP/截图脚本。已有 Playwright 可以使用，安装新的依赖或浏览器不能成为每次横幅任务的固定步骤。

导出前等待字体、图片和异步排版完成，冻结动效与不稳定内容。截取画布元素而不是整个页面；目标 PNG 通常使用 DPR 1，用户要 2x 时报告真实物理尺寸。字体替换、滚动条或默认页面 margin 会改变构图，必须检查。

## 两类证据

1. **数值检查**：check_export.py 是只读 Python 标准库工具。它验证 PNG signature、IHDR、必要块、CRC 和文件边界，输出物理宽高、字节数及是否含 alpha 能力。脚本不解码像素，也不测量有效透明区域；完整图像解码与查看仍由图片查看器执行。
2. **视觉检查**：实际打开导出图，逐字核对文案、Logo 比例、主体裁切、文字溢出和平台安全区；将原尺寸或目标显示尺寸纳入查看。小广告不要只在放大视图中验收。

校验失败时根据失败项重新导出；不要仅改文件扩展名、修改 PNG header 或 DPI metadata 来骗过检查。PNG 仅是本脚本支持的导出检查格式；用户需要 JPEG/WebP 时使用环境可用的图像检查能力核对并说明格式。

## 交付记录

预览 + 文件链接 + 物理尺寸 + 格式 + 文件大小 + 可编辑源；用户需要多个版本时列出各版本规格。文件大小限制由平台或用户提供，不把 5MB 示例当全平台规则。发布或上传属于用户任务的后续动作，素材制作本身不暗示发送到外部账户。
