# 演示、比较与时间线布局

从上游 slides 的 Product Demo、Two Column Split、Comparison Table 和 Timeline 提取适用于技术材料的模式。

产品演示：任务/输入 → 实际界面或操作 → 输出 → 适用边界。截图可保留真实界面，关键标签、解释和路径使用原生可编辑对象；不能整页截图代替用户要求的可编辑架构图。

双栏比较：只比较一个主要维度，左/右的信息粒度、单位和条件对应。参数不完整时标记不可比；营销前后对比不能替代技术验证。

时间线：按版本、事件或执行阶段组织，明确日期、依赖和验收点。未来路线是计划，不能用确定语气把预期发布时间写成事实。

机制页：概要图 + 关键步骤，必要时拆为总览与局部放大。保持箭头和标签准确，不为视觉节奏引入虚构数据流。页面变化服务认知任务，不强制三列卡片、全幅背景、居中排版或自动动效。

仍以 Presentations 构建/渲染 PPTX，使用原有证据账本与 deck-review。HTML 模板、外部 CDN、Chart.js 和强制情绪弧线不进入执行层。
