# 有证据的叙事与布局

从上游 slides 的 PAS、FAB、Before–After–Bridge 和 AIDA 吸收组织方式，按投资人问题选择，不能用公式制造焦虑、稀缺或虚构社会证明。

- 问题 → 影响 → 方案：影响必须有资料支持；没有数值就描述可观察问题或验证计划。
- 功能 → 能力 → 用户价值：说明机制与适用条件，避免把预期收益写成已证明结果。
- 现状 → 目标 → 路径：区分实际牵引和未来假设，给出里程碑与验证方法。
- 引起关注 → 证据 → 下一步：行动与融资用途匹配，不默认使用夸张口号或限时 CTA。

| 页面任务 | 适用布局 | 验证重点 |
| --- | --- | --- |
| 核心牵引 | 关键指标 + 时间趋势 | 时间、分母、累计/期间、真实来源 |
| 产品价值 | 产品截图 + 少量原生注释 | 实际界面、可读字号、主张边界 |
| 竞争 | 同口径比较表 | 比较标准完整，未知格注明未知 |
| 路线与融资 | 时间线 + 阶段验收 | 金额、用途和可验证里程碑 |
| 团队 | 与执行相关的经验分组 | 真实人员及相关经历 |

可调整章节顺序，不强制固定十页或在三分之一处插入全幅图片。客户 Logo/证言只有真实且可用时加入。标题表达可支持的结论，PPTX 构建继续使用 Presentations；图表和关键文字保持所需可编辑性。
