# A 股披露与研究分支

仅用于上海证券交易所、深圳证券交易所或北京证券交易所的 A 股公司。它补充通用基本面框架，不替代行业手册，也不延伸到交易信号或仓位建议。

## 1. 身份与时点

先确认：公司全称、股票代码、交易所、板块（主板/科创板/创业板/北交所）、证券类别、上市状态、报告币种、会计准则、财年截止日、合并口径和复权口径。存在 A/H、A/B 或多地上市时，分别记录股本、价格、币种和披露差异。

报告必须写明：纳入的最新法定报告期、公告发布日期、后续事件检查截至日期、当前价格与总股本截至日期。停牌、退市整理、风险警示或重大资产重组期间，不得把旧价格当作正常可交易估值锚。

## 2. 一手来源

事实底稿优先级：

1. 上交所、深交所、北交所披露页和公司法定公告；
2. 巨潮资讯网中的法定公告原件；
3. 公司官网投资者关系材料，用作第一方补充；
4. 证监会、交易所问询函、监管措施、纪律处分和行政处罚；
5. 聚合器、行情终端和媒体只用于导航或交叉检查。

同一公告的转载页不是独立来源。每个承重数字记录 PDF 页码或表格位置；网页行情记录查询时间。第三方数字与法定公告冲突时，以公告为准并记录冲突。

## 3. 期间与口径

- 年报通常是审计底稿核心；半年报和季报的审计状态必须显式记录，不得默认已审计。
- TTM 使用 `最近完整年度 + 当年累计期 - 上年同期累计期`，三段必须采用相同合并范围、币种、单位和重述口径。
- 不把单季环比直接年化；春节、促销、交付验收和政府补助会造成明显季节性。
- 同时保留归母净利润与扣非归母净利润。解释非经常性损益组成，而不是机械选择较好看的口径。
- 发生会计政策变更、前期差错更正、并表范围变化或同一控制下合并时，重建可比历史并标注桥接过程。

## 4. A 股专属承重检查

每项必须标为 `checked`、`not_available` 或 `not_applicable`，并提供来源或原因：

1. **审计意见**：意见类型、关键审计事项、强调事项、持续经营重大不确定性、审计师变更。
2. **扣非与非经常性损益**：政府补助、公允价值、资产处置、债务重组等对利润的贡献和持续性。
3. **关联交易与资金占用**：控股股东及关联方借款、担保、异常预付款、非经营性占用和整改进展。
4. **质押与冻结**：控股股东及一致行动人质押比例、司法冻结、被动减持风险和变化趋势。
5. **监管记录**：问询函、监管措施、纪律处分、立案调查、行政处罚及公司回复是否解决核心疑点。
6. **研发资本化**：资本化比例、开始时点、减值、费用化后的利润敏感性及同行可比性。
7. **重大重组与商誉**：交易对价、商誉、业绩承诺、补偿履行、并表贡献、减值测试和承诺期后的表现。

国企还要区分政策目标与股东回报；民企要加强控股股东资金链、质押和关联方检查。标签不是结论，证据才是。

## 5. 估值与证伪

至少保留当前倍数、反向 DCF 和 Bear/Base/Bull 情景。不要因为 A 股存在涨跌停、题材或流动性溢价就降低基本面证据门槛。

证伪条件应可观察，例如：

- 经营现金流/扣非净利润连续两期显著低于历史正常区间；
- 应收或存货增速持续高于收入且缺乏业务解释；
- 监管问询回复无法解释资金流向或会计处理；
- 业绩承诺期后利润、现金流或订单快速回落；
- 质押、冻结、关联担保或非经营性占用恶化。

## 6. 机械数据门

在 intake 顶层加入：

```json
{
  "market_profile": "CN-A",
  "a_share": {
    "exchange": "SSE",
    "board": "main",
    "primary_sources": [],
    "ttm_bridge": {
      "full_year": "FY2025",
      "current_ytd": "H1 2026",
      "prior_ytd": "H1 2025",
      "basis": "consolidated; same units and restatement basis"
    },
    "checks": {}
  }
}
```

运行 `python scripts/verify_a_share.py <intake.json>`。使用 `--template` 获取完整模板。它先执行 `verify_data.py` 的通用来源、口径、单位、期间和时效检查，再验证本页七项底稿是否被显式处理；出现 TTM/LTM 数据时，还会要求保存 `完整年度 + 当年累计 - 上年同期累计` 的桥接记录。没有使用 TTM 时可省略 `ttm_bridge`。

验证通过只说明底稿结构完整、缺口已披露，不说明数字真实或投资结论正确。深度模式仍须执行 challenge pass 和报告 linter。
